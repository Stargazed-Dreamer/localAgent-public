# 行业研究实战范式工具箱

本文件是 [deep_research skill](file:///f:/<project_root>/.agents/skills/deep_research/SKILL.md) 的子参考，专注**商业对象**（行业/公司/商业产品）研究的强化工具箱。源自小黑盒文章《以机场行业为例：教大家如何从零研究一个新行业》的方法论提炼，适配本项目的深度研究流程。

## 何时读本文件

- 研究对象是**行业**（如"机场行业""光伏行业""奶茶行业"）→ **必读，全套工具箱都用**
- 研究对象是**公司**（如"上海机场""宁德时代"）→ 必读，重点用商业模式拆解 + 财务拆解
- 研究对象是**商业产品**（如"ChatGPT""某 SaaS"）→ 读商业模式拆解 + 单位经济模型
- 研究对象是**概念/技术/人物** → 跳过本文件，用横纵框架主导

## 核心理念

行业研究的本质不是罗列数据，而是**搞清楚这个生意靠什么赚钱，以及为什么不同玩家赚的不一样多**。

文章作者的原话翻译成方法论：

> 无论任何行业，第一步，也是最重要的一步，就是先搞明白这个行业的商业模式是什么。更接地气的说法就是，这个行业到底是靠什么赚钱的？赚的是辛苦钱，还是技术钱，还是牌照钱？合理利润率是什么水平？什么因素会影响他赚钱？

## 5 步工具箱

### 步骤 1：商业模式拆解（靠什么赚钱）

**目标**：用一句话说清这个行业/公司靠什么赚钱，并判断这门生意的本质。

**操作**：
1. 把"商业模式"翻译成接地气的问题：
   - 靠什么赚钱？（收入来源）
   - 赚的是辛苦钱、技术钱、还是牌照钱？（生意性质）
   - 合理利润率是什么水平？（盈利能力）
   - 什么因素会影响它赚钱？（驱动因素）
2. **先用常识思考**（不要一上来就搜）：用户/旁观者视角能想到什么？这些初步判断作为假设
3. 再搜集资料验证/修正假设

**示例（机场行业）**：
- 常识假设：机场靠店铺租金赚钱？但小机场没几家店怎么活？靠政府补贴？
- 资料验证：机场收入 = 航空性业务收入（起降费/服务费，民航局定价）+ 非航空性业务收入（租金/广告/免税店分成）
- 本质判断：航空性业务是"薄利多销走量"（受价格管制），非航空性业务是"流量变现"（赚增值）。一线城市机场 = 航空 + 商业地产；二三线机场 = 纯公用事业

### 步骤 2：收入结构拆解（哪些业务真赚钱）

**目标**：把总收入拆成 2-N 个业务板块，找出真正赚钱的业务。

**操作**：
1. 从年报/招股书/行业报告找收入分项数据
2. 计算各板块占比
3. **如果可能，估算各板块毛利率**（公开数据没有时要诚实标注"未披露"）
4. 找出"收入占比不高但利润占比高"的隐藏金矿，和"收入高但不赚钱"的苦活

**示例（机场行业）**：
- 上海机场营收拆解：航空性收入 < 50%，非航空性收入 > 50%
- 真正赚钱的：免税店分成 + 机场 VIP 贵宾业务
- 不赚钱的：纯飞机起降业务（价格管制，薄利）
- 洞察：机场的"消费/免税属性"比"机场属性"更决定其盈利能力

### 步骤 3：单位毛利范式归因（解释量增价跌和分化）

**目标**：用 `单位毛利 = 单位营收 - 单位成本` 解释两个核心问题：
1. 为什么"量增价跌"（客流/销量恢复了，但利润没恢复）？
2. 为什么"结构性分化"（A 强 B 弱，差距怎么来的）？

**范式说明**（作者从钢铁行业迁移到机场）：
- 单位营收：每生产/服务一个单位能收多少钱（取决于产品质量/附加值/定价权）
- 单位成本：每生产/服务一个单位要花多少钱（取决于原材料/规模/管理）
- 二者作差 = 单位毛利。优秀玩家要么单位营收高，要么单位成本低，或两者兼有

**操作**：
1. 定义"单位"：行业不同单位不同（机场=每架次飞机，钢铁=每吨钢，SaaS=每用户，电商=每订单）
2. 收集各玩家的单位营收、单位成本数据（或可推算的代理指标）
3. 做一张**单位经济模型表**（研究对象 vs 主要竞品对比）
4. 用这张表解释现象

**示例（机场行业，解释量增价跌）**：
| 机场 | 2019 单位营收（万/架） | 2025 单位营收 | 航空性（固定） | 非航空性（变动） | 解释 |
|------|------|------|------|------|------|
| 上海两场 | 2.3 | 1.8 | 0.9 | 1.4→0.9（-36%） | 国际旅客未恢复 + 免税合同重签（保底 61亿→7亿） |
| 首都机场 | ~2.0 | 下降更大 | 0.9 | 下降更大 | 同上 + 新机场转固折旧 |
| 二三线 | ~1.0 | ~1.0 | ~0.9 | ~0.1 | 没有免税/广告，本就是辛苦钱 |

**洞察**：客流恢复了但利润没恢复，因为**单位营收的非航空性部分塌了**（国际旅客少 + 免税合同重签）。一线机场"量增价跌"，二三线机场"量价都平"（本就赚辛苦钱）。

### 步骤 4：成本结构拆解（规模效应强弱）

**目标**：判断行业是高固定成本还是高可变成本，决定竞争本质。

**操作**：
1. 找成本结构数据（年报/招股书/行业研报）
2. 拆成固定成本（人工/折旧/财务费用）vs 可变成本（原材料/能耗/计件）
3. 判断规模效应强弱：
   - **高固定成本 + 低可变成本** = 强规模效应（客流越大单位成本越低，如机场、铁路、SaaS）
   - **高可变成本 + 低固定成本** = 弱规模效应（成本大头是原材料，如钢铁、化工、贸易）

**示例（机场行业）**：
- 成本结构：人工 40% + 折旧摊销 25% + 运营维护 25% + 期间费用 10%
- 判断：高固定成本、低可变成本 → **强规模效应**
- 对比：与钢铁/化工（高可变成本）完全相反
- 洞察：机场是"客流越大越赚钱"的生意，2022 年客流腰斩时单位成本翻倍

### 步骤 5：结构性分化解释（为什么 A 强 B 弱）

**目标**：把不同玩家的表现差异，最终追溯到单位营收或单位成本的差异上。

**操作**：
1. 列出主要玩家的关键指标对比（营收/利润/单位营收/单位成本/客流量）
2. 识别分化方向（谁强谁弱）
3. **用步骤 3、4 的范式归因**：
   - 强在单位营收高？→ 区位好/定价权强/附加值高（如一线机场国际旅客多，免税分成高）
   - 强在单位成本低？→ 规模大/折旧少/管理好（如客流恢复后单位成本回到 2019 水平）
   - 弱在单位营收低？→ 区位差/无增值业务（如二三线机场无免税）
   - 弱在单位成本高？→ 新机场转固折旧/客流不匹配设计吞吐量（如首都机场 2019 新机场转固）
4. 找出"反常识"的分化（如旅游省份机场恢复比一线好），解释背后的特殊因素

**示例（机场行业，解释东中西部分化）**：
- 现象：东三省和中部机场客流未恢复到 2019，西部却强势
- 归因（评论区补充的洞察）：东部去中部坐高铁（京沪/京广高铁舒适区），飞机被替代；去西部只能坐飞机（山区/距离远）。分化不是机场问题，是**高铁对航空的替代效应**在不同区域不同
- 启示：研究不能只看行业内部，要考虑**替代品竞争**

## 与横纵框架的融合

行业研究实战范式不是独立的方法论，而是**嵌入横纵框架的强化工具**：

| 横纵框架部分 | 行业范式如何强化 |
|------|------|
| 纵向分析 - 起源 | 商业模式拆解：这个生意一开始靠什么赚钱？现在呢？变了什么？ |
| 纵向分析 - 演进历程 | 单位毛利范式：每个关键节点的"价跌"或"量增"用单位营收/成本解释 |
| 横向分析 - 竞品对比 | 单位经济模型表：把竞品拉到同一张表比单位营收/成本 |
| 横纵交汇 - 历史塑造当下 | 路径依赖：哪些历史决策锁定了今天的单位营收/成本结构？ |

## 反模式（不要这样做）

1. **只罗列数据不归因**：写"2025 年旅客吞吐量 XX 亿，同比增长 X%"——这是统计局的工作，不是研究。要解释为什么增长、增长的质量如何
2. **只说分化不说原因**：写"一线机场盈利强，二三线弱"——这谁都知道。要用单位毛利范式解释到"因为一线的单位营收有免税分成，二三线没有"
3. **忽略替代品竞争**：研究机场只看机场之间比，不看高铁对航空的替代——文章作者正是靠评论区补充才补全这个视角
4. **装全知**：研究停在案头就说停在案头，没和业内专家交流就说没交流。文章作者明确写"以上研究仅仅停留在案头工作的程度"
5. **用术语吓人**：把"靠什么赚钱"写成"商业模式分析"，把"赚多少"写成"盈利能力评估"——接地气的词更有洞察力
6. **跳过常识直接搜**：作者强调"不要小看常识，常识往往是很重要的"。先用旁观者视角思考，再搜资料验证，能发现真正的信息缺口

## 数据来源清单（商业对象）

| 数据类型 | 来源 | 可信度 |
|---------|------|--------|
| 行业总量数据 | 行业协会/监管机构官方统计（如民航局、中汽协、国家统计局） | 高 |
| 公司财务数据 | 上市公司年报/季报、招股书、发债主体公开财报 | 高 |
| 行业财务对比 | 券商深度研究报告（Wind/慧博/东方财富） | 中（注意券商倾向性） |
| 用户口碑 | GitHub Issues、Reddit、知乎、行业论坛、应用商店评论 | 中（需交叉验证） |
| 定价/合同细节 | 公司公告、招投标公告、合同重签公告 | 高 |
| 行业专家观点 | 行业媒体原创报道、券商电话会纪要 | 中（注意利益相关） |

> **关键提醒**：发债主体（如各省机场集团）的财务数据比单个公司更透明，因为发债必须公开披露。研究行业时优先找发债主体的公开财务数据。
