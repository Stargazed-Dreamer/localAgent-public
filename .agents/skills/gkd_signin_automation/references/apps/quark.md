# 夸克

## 用户确认流程

1. 更新提示出现时点击“暂不更新”。
2. 进入右下角“我的”。
3. 点击靠上的“会员中心”。
4. 点击“每天免费领空间”右侧“立即领”。
5. 进入下一级页面后自动签到，无需额外点击。

## 旧规则问题

旧订阅依赖很长的 WebView/FrameLayout 父子链和固定 `position`，App 布局更新后容易失效。改版时先重新查找“我的”“会员中心”“立即领”自身的 `text/desc/vid` 和最近可点击祖先；只有目标节点确实不暴露语义属性时，才保留短结构关系或带稳定锚点的位置动作。

## 2026-07-31 实机事实

- 设备分辨率为 `1200x2664`，夸克版本为 `10.10.5.1080`，Activity 为 `com.ucpro.BrowserActivity`。
- 每次冷启动回归前必须先 `adb shell am force-stop com.quark.browser`，否则夸克可能恢复会员中心或每日领空间缓存页，导致误判流程成功。
- 真正冷启动首页的底栏菜单节点稳定存在：`@FrameLayout[vid="home_toolbar_menu"][clickable=true][visibleToUser=true]`。旧规则点击其内部非 clickable `ImageView`，应替换。
- 点击菜单后显示的“会员中心”面板完全不进入 GKD/无障碍节点树，底层首页节点仍可见。纯 GKD 无法按“会员中心”文字定位，只能使用经过实机验证的 `1200x2664` 固定坐标 `(1022,390)`；必须通过 `preKeys` 串联在菜单动作之后。
- 会员中心 WebView 标题为“网盘会员管理”。“立即领”是可见但不可点击的 `TextView`，边界为 `[880,1221][1093,1316]`；`clickCenter` 已验证可进入每日领空间。
- 每日领空间页面打开后自动签到。当天已完成状态可看到“你已经连续打卡2天”和今日格子对勾，不能只凭点击日志宣称签到成功。
- `uiautomator dump` 会临时关闭并重启 GKD 无障碍服务。实时规则回归中禁止插入 dump；只在规则停止匹配或页面稳定后采集。

## 候选规则结构

使用 `preKeys` 串联四组动作：可选关闭更新提示 -> 打开底栏菜单 -> 坐标点击会员中心 -> 点击“立即领”。后两步不能作为互不相关的独立组抢跑。坐标组必须明确写入分辨率边界，App 改版或分辨率变化后重新实测。

## 下一轮采集

候选订阅导入后做一次完整冷启动回归：强制停止夸克 -> 启动首页 -> 检查菜单动作 -> 检查坐标动作 -> 检查“立即领”动作 -> 保存最终业务状态与 GKD 日志。若菜单布局漂移，优先把该跳升级为 OCR/视觉有状态编排，而不是继续延长父子链。
