# QQ 音乐

## 用户确认流程

1. 处理开屏广告与随机弹窗。
2. 进入右下角“我的”。
3. 等页面数据加载完成后点击“日签”。
4. 在二级页面点击包含“签到”的领取按钮；当前文案形如“签到领取/d+金币”。

## 风险分级

- 随机弹窗尺寸和位置变化，部分关闭图标没有无障碍节点：这一段属于 C 级，不适合纯 GKD。优先复用成熟广告订阅；仍无节点时交给 OCR/视觉 Computer Use 或人工。
- “我的”页面过早点击“日签”会进入星座页面：必须采集 `t0/t+3s/t+6s` 快照，寻找加载完成后才出现的稳定节点。找到就绪节点后用状态约束，不直接猜等待秒数。
- 签到按钮文案会变化：采集当前页面后，用稳定前缀/包含文本和弹窗上下文消歧，不能沿用旧“立即签到”精确文案。

## 下一轮采集

需要四组证据：开屏大弹窗、小弹窗、刚进入“我的”、等待后正确“日签”页面。记录每组 Activity、关闭图标是否有节点，以及错误星座页和正确签到页的可访问差异。
