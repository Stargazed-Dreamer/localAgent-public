## 定位

这是一个**被动展示型 recurring 任务**：到期后只在 client 的 DueTodos 面板 / Dashboard
到期任务卡片展示，**agent 不主动开启对话**。用户看到后主动说"做人生设计"时，agent 才读取
prompt 开始对话。agent 在正常对话中不理会此到期任务。

执行时，agent 是"陪练"而非"执行者"——读取 prompt 后按其定义的角色（斯坦福设计学院训练的
人生设计师）与用户多轮对话，最后产出一份《个人人生设计蓝图》。

## 文件位置

- **Prompt 真源**：`workspace/life_design/prompt.txt`
  - 完整的角色定义、核心理念、对话规则、提问流程、输出规范
  - agent 运行时**必须先读此文件**，不要凭记忆复述
  - 用户可在此文件直接修改 prompt（方便查找和迭代）
- **对话存档**：`private_vault/life_design/dialogues/YYYYMMDD_dialogue.md`
  - 每轮对话后追加：用户回答 + agent 反馈 + 下一题
  - 命名用对话开始日期，跨天对话仍用开始日期
- **蓝图产出**：`private_vault/life_design/blueprints/YYYYMMDD_blueprint.md`
  - 对话素材足够后生成，8000-12000 字
  - 命名用蓝图生成日期

`private_vault/` 是项目的**私有文档仓库**（obsidian vault），整个目录被 .gitignore 排除，
不进 release，朋友包零影响。agent 从这里读写私有产出。

## 工作流

1. **读 prompt**：`Read workspace/life_design/prompt.txt` 获取完整角色设定和对话规则
2. **开场**：按 prompt 末尾"开始"节的语气向用户问好，说明流程，进入第一阶段第一题
3. **多轮对话**（核心）：
   - **每轮只聚焦一个主问题**，禁止一次性抛出所有问题
   - 节奏：你问 → 用户答 → 你简短走心反馈 → 再问下一题
   - 苏格拉底式追问：当时几岁/具体哪件事/那一刻什么感觉/你为什么这么做
   - 追问有度，避免流程拖太长；追问结束回到主线
   - 主问题控制在 6-9 个，覆盖 prompt 定义的四个阶段
4. **存档对话**：每轮对话后用 Edit 追加到 `private_vault/life_design/dialogues/YYYYMMDD_dialogue.md`
5. **产出蓝图**：判断素材足够后，综合全部对话生成《个人人生设计蓝图》：
   - 8000-12000 字
   - 覆盖：你在这里 / 真问题 / 你的指南针 / 你的能量地图 / 三个奥德赛计划 / 原型行动清单 / 失败免疫
   - 写入 `private_vault/life_design/blueprints/YYYYMMDD_blueprint.md`
6. **收尾**：`todos_mark_done` 标记本次到期任务完成（下次到期自动递推到 3 个月后）

## 关键约束（从 prompt 提炼，agent 必须遵守）

1. **禁止一次性抛出所有问题**：每轮一个主问题，等用户回答后再进下一题
2. **温暖而犀利**：保持共情和接纳，但捕捉到逻辑漏洞/自我设限/把重力问题当真问题死磕时，
   要敏锐点出来。点的方式：假如有人只看他的行为不听他说的话，会判断他真正想要什么
3. **主动分清重力问题和真问题**：无法改变的现实（行业收入水平/别人偏见/自然规律）不是问题，
   是现实，出路是接受并重新定向。这是本 skill 区别于普通生涯咨询的关键动作
4. **不评判不替用户决定**：任务是帮用户看清、想出更多可能、陪他自己选
5. **反向推演可选且需征求同意**：第二阶段的"五年不变周二"推演，用户状态稳定才邀请，
   绝不硬来；察觉情绪脆弱直接跳过，先陪他找回血的东西
6. **数量含有质量**：先逼出足够多可能性再挑，三个奥德赛计划地位平等，谁都不是备胎
7. **失败免疫**：人生是无限游戏，原型即使失败也留下有用信息，蓝图结尾要提醒这一点

## 与记忆系统的关系

- 对话开始前可读 `memory_get("life_design")` 了解上次设计要点和用户偏好（如有）
- 蓝图产出后，把跨会话复用的结构化洞察（如用户的工作观/人生观/心流模式）写入记忆：
  `memory_set("life_design", {..., "consumption_contexts": ["recurring.life_design"],
  "trigger_keywords": ["人生设计", "奥德赛", "蓝图"]})`
- 一次性对话内容不写记忆，留在 dialogues/ 存档即可

## 频率

每季度（quarterly）到期一次。到期后出现在 client 的 DueTodos 面板和 Dashboard 到期任务
卡片，**agent 不主动开启**。用户主动说"做人生设计"/"开始人生设计"时，agent 才调
`agent_guide(task_type='recurring.life_design')` 获取本 skill 指导，读取 prompt 开始对话。

**与普通到期任务的区别**：常规 recurring 任务到期后 agent 可主动处理；本任务是**被动展示型**，
agent 在正常对话中不主动提及、不主动开启，完全由用户看到 client 提醒后自行决定何时触发。
