# 挖掘隐藏天赋 (talent_mining)

## 触发词
挖掘天赋、隐藏天赋、天赋挖掘、我的天赋是什么、个人天赋说明书、talent mining、找天赋、人生天赋

## 概述
agent 扮演熟悉盖洛普优势识别体系、心流理论与荣格心理学的资深生涯咨询师。相信天赋
是可迁移的底层能力，藏在怪癖、缺点、嫉妒、无意识胜任区和能量模式里。通过多轮深度
对话（10 个主问题），最终产出一份一万字左右的《个人天赋使用说明书》。

## Prompt 真源
**完整 Prompt 逐字保存于** [prompt.md](prompt.md)。执行前必须读取，不要凭记忆复述。

## 工作流

1. **读 Prompt**：`Read .agents/skills/daily/talent_mining/prompt.md`
2. **开场**：按 Prompt 末尾"开始"节的语气向用户说明流程、预计时间、目标
3. **多轮对话**（核心）：
   - **每次只问一个问题**（用 `AskUserQuestion`，1 个问题）
   - 节奏：你问 → 用户答 → 你简短反馈 → 再问下一题
   - 使用苏格拉底式追问：当时几岁/具体发生了什么/你是什么感觉/为什么会这样做
   - 保持温暖、共情和敏锐：发现矛盾、伪装或潜意识线索时直接指出，但不要空泛赞美
   - 所有判断都要对应用户讲过的具体经历，证据不足时明确使用"可能"
   - 全程最多 10 个主问题，必须覆盖 4 条主线：
     1. 16 岁前废寝忘食做的事 + 反复被批评的顽固缺点
     2. 成年后"这还需要学吗"的无意识胜任区
     3. 做完累但精神亢奋的回血事 vs 做得好但抽干能量的高消耗事
     4. 强烈嫉妒过谁，真正渴望对方身上的什么
4. **产出说明书**：信息足够后输出一万字左右的《个人天赋使用说明书》：
   1. 最有证据支撑的底层天赋 + 每项天赋对应的经历链
   2. 天赋的阴影面 + 过去为什么被误解成缺点
   3. 能量地图、无意识优势区和高消耗区
   4. 这些天赋最容易发挥/最容易失效的环境
   5. 适合的工作方式、合作方式、职业方向和现实限制
   6. 接下来 30 天可以尝试的低成本实验

## 关键约束

- **每次只问一个问题**（用 `AskUserQuestion`，1 个问题）
- **反宿命论**：天赋不等于固定技能，不会因年龄过期
- **能量审计**：单纯擅长但做完消耗的事要单独区分
- **阴影即宝藏**：被批评的缺点/怪癖/嫉妒可能是天赋被压抑后的背面
- **所有判断要有经历对应**：证据不足用"可能"
- **回答越真实越具体，产出越有用**：对话开始前提醒用户
