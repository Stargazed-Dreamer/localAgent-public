### [F4-A-cross] 跨会话样本选取（已确认 = 会话内为主 + 跨会话补充）

**背景**：用户提出，多会话（每会话 = 一个源文件夹）场景下，单会话内某类样本可能高度同质化，可**跨会话聚合样本**后再做平衡/多样性选取，以拿到更丰富的样本集喂给 LLM。

**已确认方案（F4-A-cross-c）**：默认按会话内样本做 A2 多样性选取；**某类样本数不足 `MAX_PER_CAT` 时，从其它会话的同类样本借补以凑满配额**（优先借语义上差异更大的样本，沿用 F-d 分群逻辑）。既保证各会话主体隔离、又能在同质化时丰富样本。此逻辑与 `[F4-loc]` 源目录信号可联动（不同源目录的同名文件本就是天然区分信号）。

### [F4-loc] 文件所属位置（源目录）作为分类辅助信号（已确认 = 仅作 prompt 上下文）

**背景**：用户提出，文件"所属位置"有分类价值——例如同一份文件在「下载文件夹」与「微信文件文件夹」里，分类目标可能不同（来源暗示用途）。需在冲突检测 / 分类时把源目录纳入考虑。
